# うんどうかい UI 提案(デザインキャンバス)

`undoukai.html` の本番画面を、情報の重なりと表示のタイミングから見直すための提案。
**まだ実装していない、話し合うための絵**です。

- 公開先: https://claude.ai/code/artifact/1c12c930-d588-4541-beeb-bf76df0d9c95

## 中身

| ファイル | 内容 |
|---|---|
| `Main.dc.html`   | 現状の画面の再現と、重なっている箇所の印 |
| `Play.dc.html`   | プレー中の提案(常に出るのは数字2つだけ) |
| `Rule.dc.html`   | どこに何を置いていいか(UI帯 / キャラの帯 / テロップ帯) |
| `Motion.dc.html` | 決着とお祝いの動き(自動再生) |
| `Flow.dc.html`   | 6つの場面のタイムライン |
| `Parts.dc.html`  | 使う部品6つの仕様 |
| `canvas.json`    | キャンバス上の並びと付箋 |
| `build.py`       | 上の `.dc.html` を組み立てるスクリプト |
| `icons/*.png`    | `assets/buttons/` の競技アイコンを 96px に縮めたもの(キャンバス用) |

ステージの色と座標は `js/meet.js` の たまいれ(`tmDraw`)と同じ値。キャラだけ仮の絵。

## 提案の骨子

1. 常に出すのは1種類だけ。**総合点は全競技が終わった最後に1回だけ。**
2. キャラの帯(y=104-630)には何も置かない。カードは上1/3に。
3. **切り替わる前に0.3秒だけ全部消す**(区切りの「間」)。
4. 同じことを2回言わない(チーム名は色に任せる)。
   進行は丸ではなく**競技アイコンそのもの**で示し、残り時間は今の競技の台座に入れる。
5. **勝ち負けは明るさではなく派手さでつける。** 負けた側を暗くしたりぼかしたりせず、
   勝った側に紙吹雪・跳ねる動き・光を足す。負けた側は拍手のしぐさを見せる。

## 作り直し方

`.dc.html` を直すか、`build.py` を直して `python3 build.py`。
そのあとキャンバスを書き出して公開しなおす(書き出した html は .gitignore 済み)。
