# 🌈 みんなの ゲームパック

保育園の「おしごと紹介」イベント用のゲーム集です。
**子どもたちが描いた絵や園の写真を取り込んで、そのまま遊べる** 17種類のミニゲームが入っています。

ブラウザだけで動きます(インストール・ビルド・ネット接続すべて不要)。

## 🎮 あそべるゲーム

トップページは **つくる →** そのあと **みる / ひとりで / ふたりで / みんなで**(あそびかた別)と、
**🏆 うんどうかい**・**ゲーム別**(全ゲーム一覧・初期表示)のタブで切り替えます。

| タブ | なにができる |
|---|---|
| **つくる** | とりこみ・おえかき・4たくクイズ・まちがいさがし の入口(`create.html`)。それぞれ専用ページに分かれています |
| **みる** | 見ているだけで進むオートモードに直行(5ゲーム) |
| **ひとりで** | れんしゅう と ガチンコ(難易度)だけの画面に直行(11ゲーム) |
| **ふたりで** | 2人で遊ぶモードに直行(かけっこ 2Pたいせん・さかさクイズ) |
| **みんなで** | 会場のみんなで参加するモードに直行(5ゲーム) |
| **🏆 うんどうかい** | 4つの競技を続けて再生する運動会モード(`undoukai.html`) |
| **ゲーム別** | 今までどおりの全ゲーム一覧。**初期表示** |

タブから直行したときは、途中の「あそびかたを えらぶ」画面は見せていないので、
**「もどる」でトップページに1回でもどります**(`js/core.js` の `Nav.direct`)。

各ゲームの入り口は **🌈ゆるふわ** と **🔥ガチンコ** の2つだけです。

- **🌈ゆるふわ** … かちまけなし。ここに **れんしゅう**・**みんなで**・「2Pたいせん」・「みるだけ(オート)」が並びます
  - **みんなで**(黄色のボタン) … こたえを えらばずに みんなで ながめるモード。**4たくクイズ・かげえクイズ・まちがいさがし・じゃんけん** にあります
    - 4つの選択肢は押せるボタンではなく **ただのフレーム** で表示され、下の「**こたえを みる**」を押すと効果音とともに答えが大きく出ます(まちがいさがしは まちがいの場所すべてに番号つきの丸がつきます)
    - まちがいさがしの **みんなで** だけは、ながめるだけでなく **絵をタッチして探すこともできます**(時間もノルマもなし)
    - みんなで画面を見ながら声に出して答える、発表会・保育室のスクリーン向けです
    - かげえクイズは「みんなで」を押したあとに **どうぶつ / みんなの え** を選びます
  - **れんしゅう** … 時間制限も回数制限もなし。**ほんばんへ** ボタンで、そのままガチンコの かんたん に進めます
    - 終わりがあるゲーム(カードあわせ・おえかきパズル)はクリア画面に、終わらないゲーム(もぐらたたき・なわとび・こえで ジャンプ・おえかきのたび)は画面の下にずっと出ています
  - みるだけ(オート)があるのは **かけっこ** と、観戦ゲーム(みんなの せかい・たまいれ・ドッヂボール・リレー)です
- **🔥ガチンコ** … かんたん→ふつう→むずかしい をクリアで順に解放。段階ごとにランキングが残ります

ボタンの色は全ゲームで共通です。

| ボタン | 色 |
|---|---|
| みんなで・2Pたいせん | 🟡 きいろ |
| れんしゅう | 🔵 あお |
| かんたん | 🟢 みどり |
| ふつう | 🟠 オレンジ |
| むずかしい | 🟣 むらさき |

キャラや絵が必要なゲームでは、**先に入り口(あそびかた)を選び、そのあと専用の画面でキャラ・絵を選びます**。
「みるだけ(オート)」など選ぶ必要がないものは、そのまま始まります。

### ← もどる は 1つずつ

「← もどる」と、スマホ・タブレットの **バックキー(ブラウザの もどる)** は、**画面を1つずつ**もどります。
いきなりトップページには出ません(`js/core.js` の `Nav`)。

```
あそぶ → (チームわけ) → えらぶ → トップページ
```

キャラ・絵をえらぶ まど が開いているときは、まず その まど が閉じます。

ただし **トップのタブから直行したとき**(`?mode=...`)は、途中の画面を見せていないので
1回でトップページにもどります。

| ゲーム | あそびかた | つかう素材 |
|---|---|---|
| 🧩 ぱずる | 1枚の絵がジグソー形のピースにバラバラに。れんしゅう(6ピース)/ ガチンコ(12・20・30ピース)。時間制限はなく、ガチンコはクリアまでの秒数を数えてランキングにする | 絵・写真なんでも |
| ❓ クイズ | 4択クイズ。問題は `js/quiz-data.js` で自由に編集。**みんなで**は選択肢がフレーム表示になり「こたえを みる」で答えを大きく出す | — |
| 🌈 おえかき ぼうけん | 子どもの描いたキャラが手足を動かして歩く横スクロール。れんしゅうはゴールなしで左右どこまでも歩け、⭐はランダムに出て数えない。ガチンコは⭐を10こ集めてゴールへ | キャラの絵+背景の絵 |
| 🌳 みんなの せかい | 取り込んだ絵がぜんぶ画面の中で生活。**おかの せかい / みずの せかい / いえの なか / ひまわり ばたけ** を切りかえられる。タッチすると跳んで名前が出る(観客向け) | キャラの絵 |

| 🎤 こえで ジャンプ | マイクに向かって声を出すとキャラが浮かんで⭐あつめ。会場全員で叫べる。れんしゅうは時間むせいげんで、⭐は出るけれど数えない | キャラの絵 |

| 😆 ふくわらい | 目・鼻・口をドラッグして顔づくり。めかくしモードあり。取り込んだ顔の絵からパーツを切り出して遊べる | 顔の絵(パーツせってい)/ なくてもOK |
| ✊ じゃんけん | 描いたキャラとじゃんけん勝負。**みんなで**は「ぽん!」で会場全員参加、ガチンコは **てんすうを ためる**(かち3てん・連勝で5,7,9…とアップ・あいこ1てん。負けても減らずゲームオーバーなし) | キャラの絵 |
| 🪢 なわとび | リズムに合わせてタイミングよくジャンプ。ゆるふわ(れんしゅう)/ガチンコ(3段階解放+ランキング)の2モード | キャラの絵 |
| 🧺 たまいれ | えらんだキャラが2チームに分かれ、左右のかごへ全自動で玉入れ。時間がきたら1こずつ数えて発表 | キャラの絵 |

はじめから「子どもの絵ふう」のサンプルキャラが入っているので、**何も取り込まなくても全ゲーム遊べます**。

### 🏆 うんどうかい(あたらしい機能)

トップの **「🏆 うんどうかい」** タブ(`undoukai.html`)は、**4つの競技を続けて再生する運動会モード**です。
大画面に映しておけば、はじめから終わりまで見ているだけで1つの運動会になります。

1. **さんかする キャラを えらぶ**(タッチで選ぶ・はずす)
2. **チームわけ**(自動。**チーム名は自由に変更できます**。キャラをタッチすると反対のチームへ移動、🎲ボタンで割りなおし)
3. **きょうぎを オン・オフ で えらぶ** … **かけっこ / たまいれ / ドッヂボール / リレー**
4. **けってい!** を押すと、オンにした競技を上から順番に全自動で再生します
5. 最後に **総合得点で優勝チームを盛大に発表**(紙ふぶき・ファンファーレ・勝ったチームみんなでおいわい)

- 得点は **勝ち2てん・ひきわけ1てんずつ**。競技のあいだに得点板が出ます
- 競技中の「この きょうぎを とばす」を押すと、その競技は引き分けあつかいで次へ進みます
- 参加キャラ・チーム名・競技のオンオフは、その端末のブラウザに保存され、次に開いたときも残ります

> 各競技は単独のゲームとしても遊べます(かけっこ・たまいれ・ドッヂボール・リレー)。
> うんどうかいの中では時間を短めにした「ダイジェスト版」で再生されます。

### 🎤 キャラの声(あたらしい機能)

「とりこみ・せってい」でキャラごとに **4種類の声を録音**できます(1つ最長10秒)。

- **よろこび**(やったー! わーい) … 対戦で**勝ったとき**に鳴る
- **あいさつ**(こんにちは やっほー) … タッチしたときに鳴る
- **おどろき・いたみ**(いたっ! うわっ!) … タッチしたときに鳴る
- **しっぱい**(そんなぁ… ざんねん) … 対戦で**負けたとき**に鳴る

録音した声は次のゲームで自動的に使われます(未録音なら従来の効果音のまま)。

- **みんなの せかい**:キャラをタッチすると、よろこび・あいさつ・おどろき のどれかをランダムで再生
- **じゃんけん**:キャラが勝てば「よろこび」、負ければ「しっぱい」
- **かけっこ(レース)**:声が重ならないよう、**勝ったキャラの「よろこび」だけ**を再生

> 声は画像と同じく **その端末のブラウザ内(IndexedDB)だけ**に保存され、公開サイトには含まれません。
> マイクは **`http://localhost` かHTTPS** で開いたときだけ使えます(バックアップzipには声も含まれます)。

## 🚀 起動のしかた

Chrome(または Edge)推奨です。

```sh
./serve.sh        # Mac / Linux
serve.bat         # Windows(ダブルクリックでOK)
```

起動したら ブラウザで **http://localhost:8765** を開いてください。

> `index.html` のダブルクリックでもほぼ動きますが、
> 「こえでジャンプ」「さかさクイズ」「キャラの声の録音」のマイクと「カメラでとる」はセキュリティ上
> `http://localhost` で開いたときだけ使えます。スクリプト起動がおすすめです。

Python が無いPCの場合は、任意の静的サーバー(`npx serve` など)でも動きます。

### 🔳 全画面であそぶ

どのページも **右上の小さい丸ボタン**で全画面に切り替えられます(もう一度押すと戻る/`Esc`でも戻れます)。
大画面に映すときにブラウザのアドレスバーやタブが消えるので、ゲームが大きく見えます。
ページを移動すると全画面はいったん解除されるので、遊ぶゲームの画面で押してください。

> ボタンは全画面に対応したブラウザだけに出ます(iPhoneのSafariは全画面に非対応のため出ません。iPad・PCのChrome/Edge/Safariは対応)。

全画面ボタンを押すと、あわせて**横画面にする**ようブラウザにお願いします。
iPadのSafariはページから画面を回せないので、そのときは「よこむきに してね」のおしらせが出ます
(画面の向きのロックを切って本体を横にすると消えます)。

### 🖥 あそんでいるあいだの画面

ステージ(canvas)のあるゲームは、あそび始めると**画面いっぱい**になります。

- ステージは**絵の縦横比のまま**、いちばん大きく入るサイズに合わせます(たてに潰れません)。
- スコア・ボタン・ヒントはステージの**上に重ねて**表示するので、**スクロールしません**。
- 「もどる」は左上のアイコンだけのボタンです。**わざと少し画面の外にはみ出して**あるので、
  こどもがまちがえて押しにくく、おとなはすぐ押せます。
- おえかきの道具は右の**ドロワー**(「🎨 どうぐ」を押すと出る)にしまってあり、
  よく使う「いろ・もどす・けしゴム・ほぞん」だけ下に浮かべています。

## 🌐 オンラインで公開する(URLひとつで開けるようにする)

完全な静的サイトなので、無料ホスティングにそのまま置けます。

### 方法1: GitHub Pages(このリポジトリから自動デプロイ・おすすめ)

`.github/workflows/deploy-pages.yml` を同梱済みです。

1. このブランチを **main にマージ**する
2. (自動で有効化されない場合)リポジトリの **Settings → Pages → Source を「GitHub Actions」** にする
3. 以降、mainにpushするたびに自動で公開・更新されます
   → URL: **https://nuigurusho.github.io/hoiku/**

※ 無料プランのGitHub Pagesは**リポジトリがPublic**である必要があります(Privateのまま公開したい場合は方法2へ)。

### 方法2: Netlify / Cloudflare Pages / Vercel(リポジトリを公開したくない場合)

- **Netlify Drop**(https://app.netlify.com/drop): このフォルダをブラウザにドラッグ&ドロップするだけ。アカウント不要で即URL発行
- Cloudflare Pages / Vercel: GitHubのPrivateリポジトリを接続して自動デプロイ(ビルド設定は「なし」、出力ディレクトリ「/」)

### オンライン公開についての大事なこと

- **子どもの絵・写真はネットにアップロードされません。** 画像は「開いたその端末のブラウザ内(IndexedDB)」にだけ保存されます。逆にいうと、当日使う端末それぞれで取り込みが必要です
- HTTPSで公開されるため、`localhost` 起動と同じく **マイク(こえでジャンプ)とカメラ取り込みがそのまま使えます**(むしろ便利になります)
- クイズの問題文(`js/quiz-data.js`)はリポジトリ/サイトに含まれて公開されるので、個人名など載せないようにしてください

## ✏️ 「つくる」でキャラや問題をつくる

トップの **「つくる」** タブ(`create.html`)は、当日いちばん使う画面です。
ここは **4つの入口をならべただけのページ** で、中身はそれぞれの専用ページにあります。

| ボタン | ひらくページ | 中身 |
|---|---|---|
| 📥 とりこみ | `admin.html` | 絵・写真の取り込み、名前かえ・トリミング・削除、バックアップ |
| 🎨 おえかき | `draw-pick.html` | 「なにを かく?」を選んでから描く。作った絵の うごきせってい・こえ・ふくわらいパーツもここ |
| ❓ ４たくクイズ | `create-quiz.html` | 園のオリジナル問題づくり |
| 🔍 まちがいさがし | `create-diff.html` | 差分画像と まちがいスポットの設定 |

ほかの画面と同じで、**どのページからも「← もどる」で1つ前に戻ります**。

### 🎨 おえかき / なにを かく?(`draw-pick.html`)

描きはじめる前に **なにを描くか** を選びます。選んだ種類で、紙の縦横比・保存先・うごきのタイプ・
**あたり**(下記)が決まります。

- **キャラクター** … 🧍にんげん / 👗スカート / 🐕どうぶつ / 🦋ちょうちょ / 👻ふわふわ
- **そのほか** … 😀かお(ふくわらい用) / 🏞️はいけい

同じページの下半分に **いままでに つくった え** の一覧があり、
行の **うごきせってい**(首・腰・中央の3本線)と **こえ**(4種類の録音)、
**ふくわらいパーツ** はここから設定します。

- うごきのタイプは **🧍にんげん / 👗スカート / 🐕どうぶつ / 👻ふわふわ / 🦋ちょうちょ** の5つ
  (「なにを かく?」の名前とそろえてあります)
  - 🐕**どうぶつ** は **あたまを左がわ** にして横むきに描きます(まえあし・うしろあしを正しく動かすため)
  - 🦋**ちょうちょ** だけは描きかたがちがい、**はねを1まいだけ**(からだは紙の左はしに半分)描きます。
    それを左右はんてんした はねと合わせて1ぴきにして、ひらひら羽ばたきながら飛びます。
    「はねのつけね」の線をドラッグすると、どこから右を鏡にするか変えられます
    (ぜんしんの絵をまん中で鏡にする、といった使いかたもできます)
- 😀**かお** はふくわらい用。**ふくわらいパーツ** で目・まゆげ・鼻・口を四角く囲みます

それぞれのリストの最後にある **＋ボタン** から、4つの方法で絵を増やせます。

1. **おえかきする**(その場でお絵かき。何を描くかは決まった状態で開きます)
2. **ファイルを えらぶ**(PDFも可)
3. **カメラで とる**
4. **元素材から きりだす**(大きな紙に何人分も描いた絵から、1人ずつ切り出す)

各セクションの **i ボタン** に、描きかた・撮りかたのコツと画像サイズの目安が入っています。

### 🎨 おえかき(`draw.html`)

- ペン・**ぬりつぶし(バケツ)**・けしゴム・もどす・やりなおし・**↔左右はんてん**・ぜんぶけす
  - ぬりつぶしは、囲まれたところをタッチするとその中だけ塗ります(線の色が違えば線でとまります)
  - **↔左右はんてん** … 🐕どうぶつ(あたまは左)・🦋ちょうちょ(からだは左)を逆向きに描いてしまったときの直し
- **あたり**(かく場所のめやす)
  - 画面に入ってから **2秒ほど点線と一言が出て、すーっと消えます**(出しっぱなしにも消しっぱなしにもしない)
  - 「どうぐ」の **あたり** でいつでも出し入れできます
  - あたりの位置は **うごきせっていの初期値**(くび0.42・こし0.70・まんなか0.5・おなか0.55)に合わせてあるので、
    そって描けば設定をさわらなくてもきれいに動きます
  - 別レイヤーに描いているので、**保存する絵には入りません**
- **少しでも描いたあと「← もどる」を押すと、保存するか聞きます**(そのまま消えないように)
- **取り込み済みの絵をあとから描き足せます**
  - 「つくる」の各行の **おえかきで なおす**、または おえかき画面の **とりこんだ えを なおす** から選ぶ
  - **うわがき ほぞん** … 同じ絵を書きかえます。名前・うごきせってい・まちがいスポット・こえは そのまま残ります
  - **べつの えとして ほぞん** … 元の絵を残したまま、新しい絵として保存します
  - 元の絵のたて・よこ比のままキャンバスが開くので、そのまま描き足せます

## 📷 子どもの絵の取り込みかた

絵の **名前かえ・DL・トリミング・カテゴリ変更・削除** は「とりこみ・せってい」で行います。

1. メニュー右上の **「とりこみ・せってい」** を開く(おとなのひとよう)
2. カテゴリを選ぶ(上から順に並んでいます)
   - **トリミング用の元素材** … 切り出したい大きな絵や写真を高画質のまま保存しておく置き場
   - **キャラクターの全身** … 動き回るゲームで使う(白い紙に濃くはっきり描いたもの◎)
   - **キャラクターの顔** … ふくわらい用の顔の絵(全身とは別に管理できます)
   - **写真・絵** … パズル・まちがいさがし用(園の写真もここ)
   - **背景の絵** … ぼうけんの舞台になる
3. 「ファイルをえらぶ」or「カメラでとる」で追加
4. **うごきせってい・こえ・ふくわらいパーツ・まちがいスポット** は「つくる」画面で設定します
5. 各絵の **「DL」** ボタンで、取り込んだ絵・写真を1枚ずつ画像ファイルとして書き出せます
6. **「トリミング」** から何枚でも切り出して各カテゴリへ保存できます
7. **「カテゴリ」** ボタンで、その絵を別のカテゴリへ移せます(一覧から選ぶダイアログ)

画像はブラウザの中(IndexedDB)に保存されます。**当日使うPCで取り込んでください。**
白背景の透過は自動なので、明るい場所で影が入らないように撮るときれいに切り抜けます。

## 💾 設定のバックアップ・お引っ越し(zip)

取り込んだ絵や設定は端末ごとに保存されるので、**別のPCへ丸ごと移したいとき**は
「とりこみ・せってい」画面の **バックアップ** から zip で書き出せます。

1. 元のPCの **「とりこみ・せってい → 💾 バックアップ」** で **「⬇️ ぜんぶ エクスポート(zip)」**
   → `hoiku-settings-日付.zip` がダウンロードされます
2. 当日使うPCで同じ画面を開き、**「⬆️ zip から インポート」** でその zip を選ぶ
   → 絵・写真・うごきせってい・まちがいスポット・ふくわらいパーツ・オリジナルクイズ・ランキングが丸ごと復元されます

zip の中身は「画像ファイル(images/)+ 設定(manifest.json)」です。外部ライブラリ・ネット接続なしで
ブラウザだけで作成/展開します。**インポートすると、その端末の現在の内容は置きかえられます**(実行前に確認あり)。

## ❓ クイズ問題の編集

園ごとの問題は **「つくる」→ ４たくクイズ** で追加するのがかんたんです(この端末の中だけに保存)。
全端末で共通の問題を変えたいときは `js/quiz-data.js` をテキストエディタで開いて書き換えます。
書式の説明もファイル内に書いてあります。園にまつわる問題(後半)は
本番前に必ず内容を差し替えてください。

## 🛠 技術メモ

- 素の HTML + Canvas + JavaScript。外部ライブラリ・ネット接続不要(オフライン動作)
- 効果音は WebAudio でその場で合成(音声ファイルなし)
- キャラの声は MediaRecorder で録音し dataURL で IndexedDB に保存(バックアップzipにも同梱)
- さかさクイズの逆再生は Web Audio API(`decodeAudioData` → チャンネル配列を反転 → `AudioBufferSourceNode`)。録音データはゲーム内でのみ使用し保存しない
- うんどうかいの4競技(かけっこ・たまいれ・ドッヂボール・リレー)は `js/meet.js` に共通エンジンとして入っており、`undoukai.html` と `games/tamaire.html` が呼び出す(単独版の `games/dodgeball.html`・`games/relay.html`・`games/race.html` は従来どおり1ファイル完結)
- キャラは「くび・こし・中心」の3線で頭・体・両足に分割し、ペープサート(紙人形)方式でアニメーション
- 画像・声は IndexedDB に保存。`とりこみ・せってい → ぜんぶ削除` でリセット
