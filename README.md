# 🌈 みんなの ゲームパック

保育園の「おしごと紹介」イベント用のゲーム集です。
**子どもたちが描いた絵や園の写真を取り込んで、そのまま遊べる** 16種類のミニゲームが入っています。

ブラウザだけで動きます(インストール・ビルド・ネット接続すべて不要)。

## 🎮 あそべるゲーム

トップページは **つくる → みる → あそぶ**(やることの流れ)と **ゲーム別**(全ゲーム一覧・初期表示)の
タブで切り替えます。

| タブ | なにができる |
|---|---|
| **つくる** | キャラクター(ぜんしん・かお)・4たくクイズ・まちがいさがしの素材づくり(`create.html`) |
| **みる** | 見ているだけで進むオートモードに直行(12ゲーム) |
| **あそぶ** | れんしゅう と ガチンコ(難易度)だけの画面に直行(11ゲーム) |
| **ゲーム別** | 今までどおりの全ゲーム一覧。**初期表示** |

各ゲームは **🌈ゆるふわ** と **🔥ガチンコ** の2つの入り口になっています。

- **🌈ゆるふわ** … かちまけなし。見ているだけで進む「みるだけ(オート)」、自分のペースで遊ぶもの、2人で操作する「2Pたいせん」がここに並びます
- **🔥ガチンコ** … かんたん→ふつう→むずかしい をクリアで順に解放。段階ごとにランキングが残ります

キャラや絵が必要なゲームでは、**先に入り口(あそびかた)を選び、そのあと専用の画面でキャラ・絵を選びます**。
「みるだけ(オート)」など選ぶ必要がないものは、そのまま始まります。

| ゲーム | あそびかた | つかう素材 |
|---|---|---|
| 🧩 ぱずる | 1枚の絵がランダムな形のピースにバラバラに。組み立てよう(4〜20ピース) | 絵・写真なんでも |
| ❓ クイズ | 4択クイズ。問題は `js/quiz-data.js` で自由に編集 | — |
| 🌈 おえかき ぼうけん | 子どもの描いたキャラが手足を動かして歩く横スクロール。⭐を10こ集めてゴールへ | キャラの絵+背景の絵 |
| 🌳 みんなの せかい | 取り込んだ絵がぜんぶ画面の中でお散歩。タッチすると跳んで名前が出る(観客向け) | キャラの絵 |
| 🏁 よーいどん! | キャラが勝手に走る「みるだけ(オート)」と、連打で競う「2Pたいせん」・CPU対戦 | キャラの絵 |
| 🎤 こえで ジャンプ | マイクに向かって声を出すとキャラが浮かんで⭐あつめ。会場全員で叫べる | キャラの絵 |
| 🕳️ もぐらたたき | 穴からひょっこり出てくるみんなの絵をタッチ! | キャラの絵 |
| 🎴 カードあわせ | 神経衰弱。カードの絵柄は取り込んだ絵になる | 絵・写真なんでも |
| 🔦 かげえクイズ | 影絵の正体を当てる。「だれの絵でしょう?」モードで発表会もできる | キャラの絵 |
| 🔍 まちがいさがし | 2枚の絵を見比べて違いをタッチ。スポットは大人が事前設定 | 絵・写真 |
| 😆 ふくわらい | 目・鼻・口をドラッグして顔づくり。めかくしモードあり。取り込んだ顔の絵からパーツを切り出して遊べる | 顔の絵(パーツせってい)/ なくてもOK |
| ✊ じゃんけん | 描いたキャラとじゃんけん勝負。「みんなでじゃんけん」モードは会場全員参加 | キャラの絵 |
| 🪢 なわとび | リズムに合わせてタイミングよくジャンプ。ゆるふわ(みるだけ・積み上げ)/ガチンコ(3段階解放+ランキング)の2モード | キャラの絵 |
| 🏐 ドッヂボール | えらんだキャラが2チームに分かれ、最後の1人が残るまで全自動で対戦。操作は画面切り替えだけの観戦ゲーム | キャラの絵 |
| 🏃 リレー | 2チームに分かれてトラックを全自動でリレー対決。バトン落とし・ころび・スパートなどのハプニングで接戦に!勝ったチームはみんなでおいわい | キャラの絵 |
| 🙃 さかさクイズ | 出題者が5問連続で声を録音 → 回答者が4択で当てる。**さかさもじ**(かんたん):さかさことば(りんご→ごんり)を読んでそのまま再生。**ぎゃくさいせい**(むずかしい):ふつうに読んだ声を機械が逆再生。全問終わると星つきのクリア画面。声はゲーム内でのみ使い保存しない | マイクだけ |

はじめから「子どもの絵ふう」のサンプルキャラが入っているので、**何も取り込まなくても全ゲーム遊べます**。

### 🎤 キャラの声(あたらしい機能)

「とりこみ・せってい」でキャラごとに **4種類の声を録音**できます(1つ最長10秒)。

- **よろこび**(やったー! わーい) … 対戦で**勝ったとき**に鳴る
- **あいさつ**(こんにちは やっほー) … タッチしたときに鳴る
- **おどろき・いたみ**(いたっ! うわっ!) … タッチしたときに鳴る
- **しっぱい**(そんなぁ… ざんねん) … 対戦で**負けたとき**に鳴る

録音した声は次のゲームで自動的に使われます(未録音なら従来の効果音のまま)。

- **みんなの せかい**:キャラをタッチすると、よろこび・あいさつ・おどろき のどれかをランダムで再生
- **じゃんけん**:キャラが勝てば「よろこび」、負ければ「しっぱい」
- **よーいどん!(レース)**:声が重ならないよう、**勝ったキャラの「よろこび」だけ**を再生

> 声は画像と同じく **その端末のブラウザ内(IndexedDB)だけ**に保存され、公開サイトには含まれません。
> マイクは **`http://localhost` かHTTPS** で開いたときだけ使えます(バックアップzipには声も含まれます)。

## 🚀 起動のしかた

Chrome(または Edge)推奨です。

```sh
./serve.sh        # Mac / Linux
serve.bat         # Windows(ダブルクリックでOK)
```

起動したら ブラウザで **http://localhost:8765** を開いてください。

> `index.html` のダブルクリックでもほぼ動きますが、
> 「こえでジャンプ」「さかさクイズ」「キャラの声の録音」のマイクと「カメラでとる」はセキュリティ上
> `http://localhost` で開いたときだけ使えます。スクリプト起動がおすすめです。

Python が無いPCの場合は、任意の静的サーバー(`npx serve` など)でも動きます。

### 🔳 全画面であそぶ

どのページも **右上の小さい丸ボタン**で全画面に切り替えられます(もう一度押すと戻る/`Esc`でも戻れます)。
大画面に映すときにブラウザのアドレスバーやタブが消えるので、ゲームが大きく見えます。
ページを移動すると全画面はいったん解除されるので、遊ぶゲームの画面で押してください。

> ボタンは全画面に対応したブラウザだけに出ます(iPhoneのSafariは全画面に非対応のため出ません。iPad・PCのChrome/Edge/Safariは対応)。

## 🌐 オンラインで公開する(URLひとつで開けるようにする)

完全な静的サイトなので、無料ホスティングにそのまま置けます。

### 方法1: GitHub Pages(このリポジトリから自動デプロイ・おすすめ)

`.github/workflows/deploy-pages.yml` を同梱済みです。

1. このブランチを **main にマージ**する
2. (自動で有効化されない場合)リポジトリの **Settings → Pages → Source を「GitHub Actions」** にする
3. 以降、mainにpushするたびに自動で公開・更新されます
   → URL: **https://nuigurusho.github.io/hoiku/**

※ 無料プランのGitHub Pagesは**リポジトリがPublic**である必要があります(Privateのまま公開したい場合は方法2へ)。

### 方法2: Netlify / Cloudflare Pages / Vercel(リポジトリを公開したくない場合)

- **Netlify Drop**(https://app.netlify.com/drop): このフォルダをブラウザにドラッグ&ドロップするだけ。アカウント不要で即URL発行
- Cloudflare Pages / Vercel: GitHubのPrivateリポジトリを接続して自動デプロイ(ビルド設定は「なし」、出力ディレクトリ「/」)

### オンライン公開についての大事なこと

- **子どもの絵・写真はネットにアップロードされません。** 画像は「開いたその端末のブラウザ内(IndexedDB)」にだけ保存されます。逆にいうと、当日使う端末それぞれで取り込みが必要です
- HTTPSで公開されるため、`localhost` 起動と同じく **マイク(こえでジャンプ)とカメラ取り込みがそのまま使えます**(むしろ便利になります)
- クイズの問題文(`js/quiz-data.js`)はリポジトリ/サイトに含まれて公開されるので、個人名など載せないようにしてください

## ✏️ 「つくる」でキャラや問題をつくる

トップの **「つくる」** タブ(`create.html`)は、当日いちばん使う画面です。

- **キャラクター / ぜんしん** … 走る・跳ぶゲームで動く絵。行の **うごきせってい**(首・腰・中央の3本線)と **こえ**(4種類の録音)がここにあります
- **キャラクター / かお** … ふくわらい用。**ふくわらいパーツ** で目・まゆげ・鼻・口を四角く囲みます
- **４たくクイズ** … 園の名前などのオリジナル問題づくり(この端末の中だけに保存)
- **まちがいさがし** … 写真・絵の **まちがいスポット** 設定

それぞれのリストの最後にある **＋ボタン** から、4つの方法で絵を増やせます。

1. **ファイルを えらぶ**(PDFも可)
2. **カメラで とる**
3. **おえかきする**(その場でお絵かき。何を描くかは決まった状態で開きます)
4. **元素材から きりだす**(大きな紙に何人分も描いた絵から、1人ずつ切り出す)

各セクションの **i ボタン** に、描きかた・撮りかたのコツと画像サイズの目安が入っています。

### 🎨 おえかき(`draw.html`)

- ペン・**ぬりつぶし(バケツ)**・けしゴム・もどす・ぜんぶけす
  - ぬりつぶしは、囲まれたところをタッチするとその中だけ塗ります(線の色が違えば線でとまります)
- **取り込み済みの絵をあとから描き足せます**
  - 「つくる」の各行の **おえかきで なおす**、または おえかき画面の **とりこんだ えを なおす** から選ぶ
  - **うわがき ほぞん** … 同じ絵を書きかえます。名前・うごきせってい・まちがいスポット・こえは そのまま残ります
  - **べつの えとして ほぞん** … 元の絵を残したまま、新しい絵として保存します
  - 元の絵のたて・よこ比のままキャンバスが開くので、そのまま描き足せます

## 📷 子どもの絵の取り込みかた

絵の **名前かえ・DL・トリミング・カテゴリ変更・削除** は「とりこみ・せってい」で行います。

1. メニュー右上の **「とりこみ・せってい」** を開く(おとなのひとよう)
2. カテゴリを選ぶ(上から順に並んでいます)
   - **トリミング用の元素材** … 切り出したい大きな絵や写真を高画質のまま保存しておく置き場
   - **キャラクターの全身** … 動き回るゲームで使う(白い紙に濃くはっきり描いたもの◎)
   - **キャラクターの顔** … ふくわらい用の顔の絵(全身とは別に管理できます)
   - **写真・絵** … パズル・まちがいさがし用(園の写真もここ)
   - **背景の絵** … ぼうけんの舞台になる
3. 「ファイルをえらぶ」or「カメラでとる」で追加
4. **うごきせってい・こえ・ふくわらいパーツ・まちがいスポット** は「つくる」画面で設定します
5. 各絵の **「DL」** ボタンで、取り込んだ絵・写真を1枚ずつ画像ファイルとして書き出せます
6. **「トリミング」** から何枚でも切り出して各カテゴリへ保存できます
7. **「カテゴリ」** ボタンで、その絵を別のカテゴリへ移せます(一覧から選ぶダイアログ)

画像はブラウザの中(IndexedDB)に保存されます。**当日使うPCで取り込んでください。**
白背景の透過は自動なので、明るい場所で影が入らないように撮るときれいに切り抜けます。

## 💾 設定のバックアップ・お引っ越し(zip)

取り込んだ絵や設定は端末ごとに保存されるので、**別のPCへ丸ごと移したいとき**は
「とりこみ・せってい」画面の **バックアップ** から zip で書き出せます。

1. 元のPCの **「とりこみ・せってい → 💾 バックアップ」** で **「⬇️ ぜんぶ エクスポート(zip)」**
   → `hoiku-settings-日付.zip` がダウンロードされます
2. 当日使うPCで同じ画面を開き、**「⬆️ zip から インポート」** でその zip を選ぶ
   → 絵・写真・うごきせってい・まちがいスポット・ふくわらいパーツ・オリジナルクイズ・ランキングが丸ごと復元されます

zip の中身は「画像ファイル(images/)+ 設定(manifest.json)」です。外部ライブラリ・ネット接続なしで
ブラウザだけで作成/展開します。**インポートすると、その端末の現在の内容は置きかえられます**(実行前に確認あり)。

## ❓ クイズ問題の編集

園ごとの問題は **「つくる」→ ４たくクイズ** で追加するのがかんたんです(この端末の中だけに保存)。
全端末で共通の問題を変えたいときは `js/quiz-data.js` をテキストエディタで開いて書き換えます。
書式の説明もファイル内に書いてあります。園にまつわる問題(後半)は
本番前に必ず内容を差し替えてください。

## 🎪 当日のおすすめ進行

1. **みんなのせかい** を大画面に映しておく(自分の絵を探して盛り上がる)
2. **クイズ**・**かげえクイズ** は全員参加(声で答えてもらう)
3. **こえでジャンプ**・**じゃんけん(みんなでモード)** は会場全体が参加者になれる
4. **ぱずる・ぼうけん・もぐらたたき** は順番にプレイ(1プレイ30秒〜1分で回転よく)
5. 事前 or 当日に子どもの絵を写真で取り込み → その場で「絵が動く!」体験

操作はすべて **タッチ / マウス / キーボード / 市販ゲームパッド** に対応しています
(ぼうけん:十字キー+ボタン、レース:連打)。

## 🛠 技術メモ

- 素の HTML + Canvas + JavaScript。外部ライブラリ・ネット接続不要(オフライン動作)
- 効果音は WebAudio でその場で合成(音声ファイルなし)
- キャラの声は MediaRecorder で録音し dataURL で IndexedDB に保存(バックアップzipにも同梱)
- さかさクイズの逆再生は Web Audio API(`decodeAudioData` → チャンネル配列を反転 → `AudioBufferSourceNode`)。録音データはゲーム内でのみ使用し保存しない
- キャラは「くび・こし・中心」の3線で頭・体・両足に分割し、ペープサート(紙人形)方式でアニメーション
- 画像・声は IndexedDB に保存。`とりこみ・せってい → ぜんぶ削除` でリセット
