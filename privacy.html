集計とプライバシーについて

匿名の利用状況

「みんなのゲームパック」では、ゲームをより使いやすくするため、公開版でゲームを開いた回数、プレイを始めた回数、クリアした回数を集計します。

プレイした端末数は、毎日作り直すランダムな匿名IDで数えます。日をまたいで同じ人や端末を追跡するためには使いません。

送信しない情報

名前、作品、写真、録音した声、作者名、クイズの内容、ランキング、機種、言語、正確な位置情報は送信しません。IPアドレスもアプリ独自の集計データとして保存しません。

保存と送信

オフライン中の記録は、この端末内に最大200件まで一時保存し、次にオンラインになったときに送信します。送信前に設定画面で集計をオフにすると、未送信の記録とその日の匿名IDを削除します。

受信した記録と匿名IDは35日後に削除し、ゲーム・日付ごとの合計数だけを残します。データはGoogle Firebase／Google Cloudの東京リージョンで処理します。Google Analyticsは使用しません。

集計は「設定」画面の「匿名の利用状況を送信」からいつでも停止できます。

Anonymous usage data

Everyone’s Game Pack counts game opens, game starts, and completions on the official site to help improve the games. Daily players are counted with a random identifier that is replaced every day and is not used to track a person or device across days.

Names, artwork, photos, recorded voices, creator names, quiz content, rankings, device models, language, and precise location are not sent. IP addresses are not stored as part of the app’s analytics data.

Up to 200 events may be held on the device while offline and sent when it reconnects. Raw events and anonymous daily identifiers are deleted after 35 days; only totals by game and date remain. Data is processed in the Tokyo region using Google Firebase／Google Cloud. Google Analytics is not used.

You can stop analytics at any time under Settings → Send anonymous usage data. Turning it off also deletes unsent events and the current daily identifier from the device.
