# うんどうかい UI ていあん(デザイン キャンバス)

`undoukai.html` の ほんばん がめんを、情報の 重なりと 表示の タイミングから
見なおす ための デザイン ていあん。**まだ 実装していない、はなしあう ための 絵**です。

- 公開さき: https://claude.ai/code/artifact/1c12c930-d588-4541-beeb-bf76df0d9c95

## なにが 入っているか

| ファイル | なかみ |
|---|---|
| `Main.dc.html`   | いまの がめんの 再現と、重なっている ところの しるし |
| `Play.dc.html`   | プレー中の ていあん(つねに 出るのは すうじ 2つだけ) |
| `Rule.dc.html`   | どこに 何を おいて いいか(UIおび / キャラの おび / テロップおび) |
| `Motion.dc.html` | 決着の うごき(じどう再生) |
| `Flow.dc.html`   | 5つの 場面の タイムライン |
| `Parts.dc.html`  | つかう ぶひん 5つの しよう |
| `canvas.json`    | キャンバス上の ならびと ふせん |
| `build.py`       | うえの `.dc.html` を くみたてる スクリプト |

ステージの いろ・ざひょうは `js/meet.js` の たまいれ(`tmDraw`)と 同じ 値。
キャラだけ かりの え。

## つくり直しかた

`.dc.html` を 直すか、`build.py` を 直して `python3 build.py`。
そのあと キャンバスを 書き出して 公開しなおす(書き出した html は .gitignore ずみ)。
